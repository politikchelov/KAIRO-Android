# KAIRO Android

Standalone Flutter Android application.

## Architecture
- Native Flutter screens and navigation.
- No WebView and no embedded KAIRO website.
- Anime discovery uses the KAIRO AniVibe HTTP endpoint.
- Shared account/backend integration will be implemented through dedicated client APIs in later stages. No service-role secrets belong in the app.

## Current status
- Native app shell and navigation.
- Native anime catalog/search screen.
- Home screen.
- Chat, favorites, profile and anime detail are clearly marked as under development.

## Build APK
1. Open the Actions tab.
2. Select **Build KAIRO APK**.
3. Wait for the workflow to finish.
4. Download the `KAIRO-Android` artifact.
